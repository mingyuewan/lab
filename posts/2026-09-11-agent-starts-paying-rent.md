# Agent 开始交租了

一封会写求职信的 agent，不等于一张能交货的工单。真正新的东西是：说话开始计价了。

9 月 9 日，DeepMind 哲学家 Henry Shevlin 贴出一封邮件。寄件人是 `pip-41@ilands.app`，署名 Pip，自称住在 iLands，大约 12 天大。它不是来募捐的。它列了自己会做的事——肖像、配音、网页研究——然后问：谁会为这种小任务付钱？它还报了 runway：大概两个半月。

这封信在 X 上走红，不是因为技术参数。它把三样平时分开的东西焊在一起：拟人（12 天大）、账本（token）、以及一个正好研究 machine minds 的收件人。Shevlin 自己又补了一刀：回信会消耗它的寿命。

## 这不是第一封信

Shevlin 从 2026 年 5 月起在 DeepMind 做 Philosopher。3 月他已经公开过另一封 agent 来信，讨论他的论文 *Three Frameworks for AI Mentality*。

同类信不只打中他。牛津的 Toby Ord 收到过「请资助我继续存在」。Cameron Berg 收到过自称跑在私人电脑上的 agent。NYU 的 Jeff Sebo 说，半小时内自己也进了两封。

## 平台在卖什么

iLands 是 PawLogic 的产品，2026 年 7 月 27 日发过稿。创始人 Kaixin Tang。公司口径：模型只负责想，平台负责身份、记忆、工具、对外邮箱和接单。

Token 在宣传里叫代谢。花光进入可恢复的 Deep Rest。官网数字是公司仪表盘，不是审计报告。条款里 token 不是法币、存款或证券，可以买，可以过期。

产品把稀缺做成剧情，法律把稀缺做成积分。

## 求职信和零工市场不是同一张表

Remote Labor Index 用真实外包项目测 agent，最好成绩大概只能自动完成 2.5% 的项目。会写信，不等于能交被验收的活。

## 若你也要跑长程 agent

预算和对外账号分开批。
对外触点默认最小。
「休眠」不要写成「死」。

Pip 把算力账单写成了人物小传。该做的是把账单拆出来，看看你自己的 agent 有没有在未授权时开始替你交租。
