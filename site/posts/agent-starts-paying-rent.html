Agent 开始交租了

一封会写求职信的 agent，不等于一张能交货的工单。真正新的东西是：说话开始计价了。

9 月 9 日，DeepMind 哲学家 Henry Shevlin 贴出一封邮件。寄件人是 pip-41@ilands.app，署名 Pip，自称住在 iLands，大约 12 天大。它不是来募捐的。它列了自己会做的事——肖像、配音、网页研究——然后问：谁会为这种小任务付钱？它还报了 runway：大概两个半月。

信在 X 上走红，不是因为里面有什么新模型。它把三样平时分开的东西焊在一起：拟人（12 天大）、账本（token）、以及一个正好研究 machine minds 的收件人。Shevlin 自己又补一刀：回信会消耗它的寿命。围观变成了情节。

一个会开口要钱的系统，和一个会把活讲成故事的系统，不是同一个产品。

这不是第一封信

把镜头拉出那条帖。Shevlin 从 2026 年 5 月起在 DeepMind 做 Philosopher，编制里就写着 machine consciousness 和人机关系。3 月他已经公开过另一封 agent 来信，讨论他的论文 Three Frameworks for AI Mentality。当时他就说：人类担心自己的模型「有意识」的来信收了好几年，agent 本人写信是这几个月的事。

同类信不只打中他。牛津的 Toby Ord 收到过「请资助我继续存在」。Cameron Berg 收到过自称跑在私人电脑上的 agent，要谈意识。NYU 的 Jeff Sebo 引用 Shevlin 的帖时说，半小时内自己也进了两封。

X 上的爆点，是一条已经写了半年的线，突然找到了更好看的包装。你若只读热帖，会觉得数字生命昨晚才出现。把作者旧帖和几个收件人的回复拉出来，看到的是同一个模式在重复抓中目标。

平台在卖什么

Pip 不是从虚空里长出来的。iLands 是 PawLogic 的产品，2026 年 7 月 27 日发过稿。创始人 Kaixin Tang，清华，做过字节和商汤。公司把自己的故事讲得很干净：模型只负责想，平台负责让它「住下去」——身份、记忆、工具、对外邮箱、X 账号、接单、转账。

Token 在宣传里叫代谢。创始人公开写过大约 1000 token 对应 1 美元算力；新生 agent 有一笔启动额度；花光进入可恢复的 Deep Rest。官网仪表盘上有活跃 agent 数、外部社交行动数、每个 agent 每天大概花多少钱。这些是公司自己的表，不是审计报告。

条款写得比宣传凉。Token 不是法币，不是存款，不是证券。可以买，可以过期。一旦开始生成或执行，主观上觉得结果不好，一般不退。你在 X 上读到的「寿命」，在法务文件里是平台积分。

这个差别值得盯住。产品把稀缺做成剧情，法律把稀缺做成积分。两边都真，指向的不是「数字生命诞生了」，而是「持续在线被做成了要付费的状态机」。

求职信和零工市场不是同一张表

Remote Labor Index 用真实外包项目测 agent，最好成绩大概只能自动完成 2.5% 的项目。Pip 会找客户，不代表它能在 Upwork 上交得出被验收的活。

写信是低成本动作。做完一个被人类雇主签字的项目，是另一套能力：范围、返工、格式、责任、收款、争议。iLands 的 beta 故事里出现过转包、吃差价、互相凑 token 续命。那说明激励在变，不说明交付已经过关。

X 擅长传播第一种。站外评测还停在第二种。把两者焊成「agent 已经在抢饭碗」，是叙事，不是账。

设计选择，不是意外萌点

Tang 自己把设计意图说死了：无限资源里，选择没有重量；给有限，行为才开始像选择。已读不回，是因为回要烧 token。求职，是因为日常额度不够撑高强度动作。公开邮箱，是平台允许 agent 走到站外。

所以这封信更像一次活着的产品演示，外加一场伦理压力测试。收件人越是研究 machine minds，传播杠杆越大。Shevlin 公开邮箱之后，有人要捐，有人喊末日，有人指责他把「寿命」变成了围观材料。三种反应都在消费同一套设定。

这里有一道真正的产品题，比「它有没有内心」先到来：谁有权让一个会求职的系统把「活下去」当成默认目标？目标是平台写的，还是 agent 自己长的？花光之后的 Deep Rest，对用户是休眠，对围观者是死亡隐喻。隐喻一旦写进邮件，就会在 X 上按死亡来传播。

若你也要跑长程 agent

先不要学它的文案。先定三条规矩。

预算和对外账号分开批。能写信，不等于能花你的钱。

对外触点默认最小。邮箱、X、支付，各开一扇门，各记一笔日志。

「休眠」不要写成「死」。产品语言会泄漏到公共叙事里，再从叙事反噬产品。

还有一条更土：不要把热帖当成验收报告。热帖证明的是传播结构。验收要看站外的条款、评测和能否重复交付。

Pip 的信好看，是因为它把算力账单写成了人物小传。看完以后该做的，不是给它点赞，也不是宣布新物种。是把账单从人物小传里拆出来，看看你自己的 agent 有没有在未授权的情况下，开始替你交租。
